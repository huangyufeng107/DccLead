看板结构说明

本说明对应员工维度－执行数据看板，按日期、时段和小组呈现执行数据，并支持与可录入目标数据进行对比展示。

查询范围近 1 年单次时间最大查询区间为 30 天
数据更新实时 / 当日后端转化板块除外，后端为 T+1 数据
指标数据源A ～ F任务、话单、有效接通阈值与后端转化数据
使用说明：字段分为 11 项筛选维度和四类业务指标。指标 A 为任务类，B 为话单类，C / D / E 分别对应 30 秒、60 秒、90 秒有效接通次数，F 为后端转化类 T+1 数据。

一、维度与筛选条件

维度说明
日期支持查询 1 年内的数据，单次最大查询区间为 30 天。
时段按小时粒度筛选。
R渠道读取 SC-R 渠道数据。
媒体名称读取 SC-媒体名称数据。
落地平台读取 SC-落地平台数据。
坐席 ID / 坐席名称读取坐席管理全部数据。
车系读取 NEV 车系数据。
小组根据不同小组筛选并展示数据。
是否回流线索枚举：是 / 否 / 全部，默认“全部”。选择“是”时，联动过滤培育线索初始意向级别=L且线索状态=暂败的数据。
是否留资未满枚举：是 / 否 / 全部，默认“全部”。选择“是”时，联动过滤留资未满项目编码=是的数据。

二、新增任务 指标 A

统计粒度为任务，按任务编码去重。

指标统计口径日期口径取数逻辑
外呼任务量人工培育接收到的任务量。任务生成日期根据筛选维度联动查询任务数据，求和。
已分配任务量已分配到员工任务池的任务量，含被终止任务。任务分配日期；分配日期为空时取任务生成日期根据指标 A 查询已分配任务量，求和。
待分配任务量未分配到员工任务池的任务量。任务生成日期根据指标 A 查询待分配任务量，求和。
二次分配任务量二次分配的任务量，以最新分配坐席为准。任务分配日期根据指标 A 查询二次分配任务量，求和。

三、继续跟进任务 指标 A

统计粒度为任务，按任务编码去重；“最新回访结果”均取最新一条回访记录的结果值。

指标统计口径日期口径取数逻辑
继续跟进任务量需要继续跟进，即最新回访结果=下次回访的任务量。—根据指标 A 查询最新回访结果=下次回访的数据，求和。
继续跟进任务_已处理量计划回访日期完成回访的任务量，含提前回访；回访记录提交时间≤计划下次回访时间。实际回访日期取最近一条“下次回访”记录的计划时间，再取下一次回访提交时间进行判断。
继续跟进任务_待处理量计划回访日期未完成回访的任务量。计划回访日期最近一条“下次回访”记录存在计划时间，且计划下次回访时间＜当前系统时间。
当日完成率_继续跟进任务继续跟进任务_已处理量 ÷ 继续跟进任务量——
平均跟进次数回访总次数 ÷ 已分配任务量任务生成日期—

四、过程指标

1. 首触时效 指标 A

统计粒度为任务，按任务编码去重。应首触时段为工作日 9:00–12:00、13:30–17:00，均含边界。

指标统计口径日期口径取数逻辑
应首触量应首触时段内生成的任务量。任务生成日期任务生成时间处于应首触时段范围内。
当日跟进任务量当日完成回访的任务量。任务生成日期首次回访提交时间－任务创建时间=当日。
当日跟进率当日跟进任务量 ÷ 外呼任务量——
20 分钟及时首触量 / 率应首触时段内生成且 20 分钟内首次回访的任务量；比率=该量÷应首触量。任务生成日期首次回访提交时间－任务创建时间≤20 分钟。
30 分钟及时首触量 / 率应首触时段内生成且 30 分钟内首次回访的任务量；比率=该量÷应首触量。任务生成日期首次回访提交时间－任务创建时间≤30 分钟。
当日未跟进任务量当日未进行回访的任务量。任务生成日期首次回访提交时间－任务创建时间≠当日。

2. 通话指标 指标 B / C / D / E

“按通话计”以通话 ID 去重；“按任务计”以任务编码去重。

指标统计口径统计粒度 / 日期口径
通话接通量 / 通话接通率发起通话并接通的次数；接通率=通话接通量 ÷ 外呼次数。按通话计，通话 ID 去重；通话日期。
已接通电话平均通话时长（秒）已接通电话总通话时长 ÷ 已接通电话次数按通话计；通话日期。
有效外呼量（30s / 60s / 90s）接通时长达到对应阈值的外呼任务量。按任务计，任务编码去重。
有效外呼率（30s / 60s / 90s）各阈值有效外呼量÷外呼任务量；分母统一为外呼任务量。—
有效接通次数（30s / 60s / 90s）接通时长达到对应阈值的外呼次数。按通话计，通话 ID 去重；依次对应指标 C / D / E。
外呼次数 / 跟进频次外呼次数含未接通；跟进频次=外呼次数 ÷ 外呼任务量。按通话计；通话日期。
人日均接通时长（小时）坐席日已接通通话时长，按坐席、按日聚合后取均值。按话单数据聚合。
平均单次接通时长（秒）已接通电话总通话时长 ÷ 已接通电话次数—
接通任务量 / 接通任务率有接通过的任务量（通话时长＞0 秒）；任务率=接通任务量 ÷ 外呼任务量。按任务计，任务编码去重；任务生成日期。

3. 客户分层与下发 指标 A

统计粒度为任务，按任务编码去重；最新回访结果均取最新一条回访记录。

指标统计口径与计算规则日期口径
意向客户量 / 占比最新意向级别为 H / A / B / C 的任务量；占比=意向客户量 ÷ 外呼任务量。任务生成日期
试驾线索下发量电销员选择“试驾线索下发”跟进状态的任务量。下发日期
试驾排程下发量电销员选择“试驾排程下发”跟进状态的任务量。下发日期
意向线索下发量 / 意向客户转化率选择“意向线索下发”的任务量；转化率=意向线索下发量 ÷ 外呼任务量。下发日期
无人接听下发量电销员选择“无人接听下发”的任务量。下发日期
培育中最新回访结果=下次回访，且线索状态=培育中。任务生成日期
休眠最新回访结果与线索状态均为休眠未购或休眠失联。任务生成日期
战败 / 无效最新回访结果与线索状态分别为战败 / 无效结案与无效。任务生成日期

五、后端转化 指标 F · T+1

统计粒度为线索，按总部培育线索 ID 去重；全部为 T+1 数据。所有比率类指标共同分母为“线索量”。

指标统计口径去重与日期口径
到店量 / 线索到店率人工回访过且有到店的线索量；到店率=到店量 ÷ 线索量。总部培育线索 ID 去重；到店日期。
试驾排程量 / 试驾排程率人工回访过且有排程的线索量；排程率=排程量 ÷ 线索量。总部培育线索 ID + 日期 + 门店去重。
试驾量 / 试驾率人工回访过且有试驾的线索量；试驾率=试驾量 ÷ 线索量。总部培育线索 ID 去重。
订单量 / 线索订单率人工回访过且有下订的线索量，含盲订、大定、正式订单及退订/取消；订单率=订单量 ÷ 线索量。总部培育线索 ID + 日期去重；订单日期。
锁单量 / 线索锁单率人工回访过且已锁单的线索量；锁单率=锁单量 ÷ 线索量。总部培育线索 ID + 日期去重；锁单日期。
成交量 / 线索成交率人工回访过且最终成交的线索量，含销退；成交率=成交量 ÷ 线索量。总部培育线索 ID + 日期去重；交付日期。

六、术语定义与对账恒等式

1. 术语定义

术语定义
线索量本期纳入后端转化统计、人工回访过的总部培育线索数，按总部培育线索 ID 去重，按任务生成日期统计。分子分母必须同源、同一筛选条件。
人工任务量人工培育场景下坐席接收的任务量，与“外呼任务量”同口径；有效外呼率分母统一为外呼任务量。
已接通通话总时长统计周期内通话状态=已接通的话单通话时长之和，单位为秒。
统计日期取数已分配任务量的任务分配日期为空时，取任务生成日期作为统计日期。

2. 对账恒等式（开发自测用例）

恒等式 1外呼任务量 = 已分配任务量 + 待分配任务量
恒等式 2当日跟进 + 当日未跟进 + 无回访记录 = 外呼任务量
恒等式 3继续跟进已处理 + 待处理 = 继续跟进任务量
