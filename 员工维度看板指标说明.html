看板结构说明

本文档对应《员工维度看板字段 11.7》（已修订版），描述员工维度-执行数据看板的全部字段定义。

  • 看板按分日期、分时段、分小组呈现执行数据；当前页面不读取目标配置，也不展示目标或完成度对比。
  • 时间最大查询区间为 30 天，支持查询 1 年内的数据。
  • 字段分为维度（筛选条件，10 个）与指标（按业务板块组织：新增任务、继续跟进任务、过程指标、后端转化、企微指标）两大类。
  • 指标按数据源划分为五类编号：指标A（任务类）、指标B（话单类）、指标C/D/E（有效接通次数，按 30s/60s/90s 阈值区分）、指标F（后端转化类，T+1 数据）。
  • 后端转化板块及企微相关指标均为 T+1 非实时数据；其余板块均为实时/当日数据。

页面展示与导出

  • 核心指标：外呼任务量、继续跟进任务量、接通率、下发率、排程率、试驾率、企微添加率。
  • 过程概览图表：每日执行趋势、小组对比、转化漏斗、最新回访结果分布、时段分布、员工排程量排行、有效外呼率与意向下发率（<30s / 30s / 60s / 90s）、外呼加微表现、企微好友沉淀。
  • 员工明细（晾晒表）：支持按表头排序，默认按外呼任务量降序；展示当前筛选结果，并支持导出 CSV（文件名“员工数据明细_日期.csv”）。明细和导出均包含“排程量”列，位于“下发量合计”之后。

核心指标、环比与图表展示规则

本节仅定义看板的展示、聚合与对比方式；各指标的基础取数、去重和日期口径仍以第二至第五节为准。页面中的指标均随当前筛选条件同步刷新。

已确认的页面展示更新：时段分布仅展示09时–20时。有效外呼率与意向下发率图表展示<30s、30s、60s、90s四档：<30s为最长已接通时长1–29秒的短接通外呼率；四档意向下发率均不含无人接听下发。员工明细“下发量合计”后展示并导出“排程量”。客户分层与下发的八张明细卡展示“占比=字段数量/外呼任务量”及周期对比；后端转化全部13项指标展示周期对比，数量类为百分比变化、率类为百分点变化。两处均仅显示涨跌符号与数值，不重复显示“环比”文字。

1. 核心指标与环比

  • 核心指标展示：外呼任务量、继续跟进任务量、接通率、下发率、排程率、试驾率、企微添加率；率类卡片主展示对应数量，并同步展示比率及环比。
  • 环比用于展示当前筛选时间区间与其紧邻的上一同等长度时间区间的变化；两期均使用相同的时段及其他筛选条件。
  • 环比计算公式：（本期值 − 上期值）÷ 上期值 × 100%；比率类指标按百分点（pp）展示差值，数量类指标按百分比展示变化。
  • 上期无数据、上期值为0而无法计算百分比，或后端T+1数据尚未产出时，环比展示为“—”。
  • 试驾率卡片主展示的试驾量及试驾率遵循指标F的T+1更新节奏；企微添加率卡片主展示的企微添加量及企微添加率遵循企微T+1更新节奏；其余核心指标按实时/当日数据展示。

3. 原型数据说明

  • 原型页面中的数值、环比和图表仅用于展示交互与版式，不代表生产环境实时经营数据。
  • 上线后应以实际接口返回的数据、数据更新状态和权限范围为准。

4. 当前页面核心指标映射

  • 继续跟进任务量：最新回访结果为“下次回访”的任务量，按任务编码去重。
  • 接通率：主展示接通量；接通率 = 接通量 / 外呼任务量。其中“接通量”为至少存在一次已接通话单的任务量，按任务编码去重。
  • 下发率：主展示下发量；下发量 = 试驾线索下发量 + 试驾排程下发量 + 意向线索下发量 + 无人接听下发量，按任务编码去重；下发率 = 下发量 / 外呼任务量。
  • 排程率：主展示排程量；排程量 = 试驾线索下发量 + 试驾排程下发量，按任务编码去重；排程率 = 排程量 / 外呼任务量。
  • 试驾率：主展示试驾量；试驾量为人工回访过且有试驾的线索量，沿用指标F的去重与更新规则（T+1）；试驾率 = 试驾量 / 外呼任务量。
  • 企微添加率：主展示企微添加量（即外呼加微量）；沿用好友添加时间及员工ID + 客户ID去重规则（T+1）；企微添加率 = 企微添加量 / 外呼任务量。
  • 意向下发率（30s / 60s / 90s）：分别以对应有效通话时长阈值下完成试驾线索下发、试驾排程下发或意向线索下发的任务量为分子，以外呼任务量为分母；不包含无人接听下发量。

术语定义

统计日期取数说明已分配任务量的分配日期为空时，取任务生成日期作为统计日期。

2. 对账恒等式（开发自测用例）

  • 恒等式1：外呼任务量 = 已分配任务量 + 待分配任务量
  • 恒等式2：当日跟进任务量 + 当日未跟进任务量 + 无回访记录量 = 外呼任务量
  • 恒等式3：继续跟进任务_已处理量 + 继续跟进任务_待处理量 = 继续跟进任务量
