新增 任务排班 · 坐席管理
坐席列表
10 列：坐席账号 / 姓名 / 手机号 / 所属团队 / 技能等级 / 业绩评分 / 状态 / 入职时间 / 操作。
新增与编辑
弹窗维护坐席账号、姓名、手机号、所属团队、技能等级（高/中/初级）、状态与入职时间。
批量修改
勾选多名坐席后统一调整所属团队、技能等级或状态，提交后回写列表并给出结果提示。
坐席转移
左右双栏穿梭选人，支持全选与已选计数，确定后批量调整归属团队。
账号映射
单独弹窗维护坐席账号与 e3sPlus 账号的映射关系，未映射坐席在列表中可快速识别。
启用与停用
列表内切换坐席状态，停用坐席不再参与线索分配与排班校验。
新增 任务排班 · 短信模板
模板列表
7 列：模板名称 / 模板类型 / 模板内容 / 状态 / 创建时间 / 操作，内容超长折叠展示。
模板类型
按用途分为提醒短信 / 回访短信 / 营销短信 / 关怀短信四类，支持按类型筛选。
变量与元数据
模板内容支持插入变量；弹窗内维护模板名称、类型与适用场景等元数据字段。
短信预览
独立预览弹窗按变量替换后的实际文案展示，便于发送前核对内容。
新增 任务排班 · 分配规则
规则列表
8 列：优先级 / 规则名称 / 规则描述 / 匹配条件 / 分配目标 / 权重 / 状态 / 操作。
优先级匹配
系统按优先级依次匹配规则，命中即按该规则的分配目标与权重下发线索。
分配目标
可选所有在岗坐席 / 高级·中级·初级坐席 / 原跟进坐席 / 对应区域团队 / 全部坐席。
权重配置
分配权重以百分比填写，同一规则下各目标权重合计需为 100% 方可保存。
新增 任务排班 · 排班管理
月度排班表
按月份查看坐席排班，点击日期单元格即可为坐席指定班次或标记休息。
班次管理
维护班次名称与时间段，排班表按班次着色，休息与在岗状态区分展示。
导入排班
按模板上传排班文件，解析后预览成功与失败行，确认后写入当月排班。
导出排班
按当前月份与筛选条件导出排班表，用于线下核对与交接。
板块入口接入
主导航新增「任务排班」一级菜单，二级菜单仅在选中该一级菜单时展示。

新增 培育策略 · 天网付费自动下发（人工）
启用开关
默认启用；关闭后配置项与「保存配置」同步禁用，已展开的多选面板自动收起。
统计对象只读
固定「人工回访任务记录」，仅统计同一回访任务下的有效人工记录，不读取 AI 外呼结果。
累计次数校验
默认 5 次，限 1～99 正整数；拦截负号、小数与科学计数，提示「请输入 1～99 的正整数」。
末次接触状态
单选，默认「无人接听」；选项取「接触状态」数据字典启用项并按序展示。
执行动作选择
可选「批量下发－无人接听下发」或「批量下发－意向线索下发」，命中后调用既有下发流程。
保存反馈
校验通过提示「人工外呼配置已保存并生效」，页脚展示最后更新人与时间。
新增 培育策略 · 天网付费自动下发（AI）
外呼类型多选
「新线索 / 门店冷线索 / 总部冷线索」多选，默认新线索，支持全选、清空与已选计数。
固定只读规则
「判断记录」固定整轮外呼最终结果、「触发时机」固定最终结果保存后立即触发。
通话状态多选
8 项原始状态（已接通/客户未接听/关机/空号/停机/拒接/接通秒挂/待返回），显示已选 X/8。
必填校验反馈
未选外呼类型或通话状态时分别提示且不保存；通过后提示「AI 外呼配置已保存并生效」。
新增 培育策略 · 天网付费线索标识
天网标识字典
新增业务字典「天网smartcode」，含高意向激活、留资未满唤醒、冷线索重激活等 8 条编码。
判定口径
仅 smartcode 命中该字典的天网付费线索参与自动下发判断，非命中线索不触发。
变更 培育策略 · 入口与路由接入

页面路由接入

批量审核
